# Lisbon Stay Analytics

Локальный аналитический инструмент хозяина жилья: сравнение цены с аналогами в регионе Лиссабона и историческое воспроизведение отзывов. Python 3.12, Streamlit, SQLite, pandas, NumPy, Altair, scikit-learn и imbalanced-learn. Автор: Sorocatii Ghennadii.

## Возможности

- Выбор объявления или ручной ввод района, типа, вместимости и цены.
- Медиана, типичный диапазон, пять категорий P10/P25/P75/P90, исключение собственного объекта, явный отказ при менее 15 аналогах.
- Гистограмма с точной ценой и выносом за шкалу.
- Последние 40 исторических отзывов, окно 90 дней, журнал рекомендаций RTAP с исходными текстами окна.
- Проверка цен на отложенных хозяевах и отдельные эксперименты Bias, Noise, SMOTE и повторной активности авторов.

## Установка на Windows

Нужны Python 3.12 с launcher `py`, PowerShell и интернет для установки библиотек и однократной загрузки данных. Откройте PowerShell в папке проекта:

```powershell
git clone https://github.com/qweclipse/lisbon-stay-analytics.git
cd lisbon-stay-analytics
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Вместо последних двух команд можно выполнить `powershell -ExecutionPolicy Bypass -File setup.ps1` после проверки содержимого скрипта.

## Данные

Источник: [Inside Airbnb](https://insideairbnb.com/get-the-data/), Lisbon, 19.09.2026. Исходные архивы, SQLite, тексты отзывов, пользовательские ID и таблицы отдельных объявлений в репозитории не публикуются. Точные URL, размеры и SHA-256 приведены в `output/data_audit.json`. Скачивайте архивы непосредственно у источника, учитывая его [условия](https://insideairbnb.com/data-policies/). Повторная публикация исходных данных не требуется для использования приложения.

```powershell
.\.venv\Scripts\python.exe download_data.py
.\.venv\Scripts\python.exe prepare_data.py
```

Загрузка проверяет SHA-256 и пропускает уже проверенные файлы. Для файлов и базы нужно около 1,2 ГБ, дополнительно место для окружения и временной базы при пересборке. Без подготовки приложение покажет инструкцию, а не демонстрационные значения. Не загружайте данные повторно при каждом запуске.

## Запуск и интерфейс

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.headless true
```

Либо `powershell -ExecutionPolicy Bypass -File run.ps1`. Откройте http://127.0.0.1:8501. При занятом порте добавьте `--server.port 8502`. Для остановки нажмите Ctrl+C.

Вкладка **Оценка цены**: найдите ID `25608771`, задайте 170 € и нажмите Enter. Вкладка **Отзывы**: запустите историческое воспроизведение, затем откройте запись журнала от 16.09.2023. Вкладка **Проверка сборки**: MAE, охват, диапазон и отдельный прогноз повторного отзыва. Все расчёты выполняются локально, API-ключи не нужны.

## Проверка и воспроизведение результатов

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Девять тестов используют небольшие искусственные записи и не требуют скачивания корпуса. Для повторного расчёта базовых экспериментов после подготовки базы:

```powershell
.\.venv\Scripts\python.exe evaluate.py
.\.venv\Scripts\python.exe experiments.py
```

Предварительная разметка не является человеческой. Дополнительный `revision_analysis.py` использует фиксированные машинные классы 60 индексированных текстов. В опубликованном ресурсе цитаты удалены; исходные тексты и ID восстанавливаются только локально из официального корпуса после `experiments.py`. Скрипт пишет локальные CSV, которые исключены из Git. Сохранённые JSON содержат только агрегированные показатели и метаданные снимка. `experiments.py` пересоздаёт пустой шаблон разметки; человеческую разметку храните отдельно.

## Ограничения

Цены относятся к предложениям, а не оплаченным проживаниям. Календарь не содержит дневных цен; недоступность не доказывает бронь. Ориентир цены фиксирован снимком 2026 года, отзывы могут быть более ранними; точность даты — день. Replay начинается с пустого окна последних 40 событий. Словарь жалоб ограничен, качество требует независимых меток. Прокси повторного отзыва описывает наблюдаемую публикацию, а не лояльность или повторное бронирование. Пять ценовых категорий отделены от SMOTE. Эффект на выручку и оптимальная цена не установлены.

Академические документы, учебные материалы преподавателя, секреты и служебные файлы агентов исключены из репозитория. Код программы не зависит от букв локальных дисков.
